## SkillGallery

Галерея изображений навыка на базе `Swiper`: показывает одно основное изображение и переключает его стрелками вперёд/назад.

### Props

- `images: SkillGalleryImage[]` — список изображений. Каждый элемент имеет тип `{ src: string; alt: string }`, где `src` — адрес картинки, `alt` — альтернативный текст.
- `loop?: boolean` — зацикливает переключение (после последнего слайда идёт первый и наоборот). По умолчанию `false`.

`SkillGalleryImage` экспортируется из модуля компонента:

```ts
export type SkillGalleryImage = {
  src: string
  alt: string
}
```

Если `images` пустой или не передан, компонент рендерит серую заглушку вместо основного изображения. Область галереи сохраняет предусмотренные размеры (`aspect-ratio`, по умолчанию `4 / 3`), поэтому отсутствие изображений не меняет раскладку страницы. Размер задаётся CSS-переменной `--skill-gallery-aspect-ratio`.

Если изображение не загрузилось, `onError` запоминает проблемный `src` и вместо повреждённой картинки показывает заглушку. Повторно тот же URL не запрашивается, чтобы не возникал цикл ошибок. Остальные слайды продолжают переключаться, а новый `src` из пропсов загружается как обычно.

Стрелки — нативные кнопки с `aria-label` («Предыдущее изображение» и «Следующее изображение»), навигация подключается через модуль `Navigation` из `Swiper`. Компонент не управляет выбором изображения — он только отображает переданный список; из состояния хранится лишь набор `src` с ошибками загрузки.

### Как подключить

```tsx
import { SkillGallery } from '@/entities/skill/ui/SkillGallery'

const images = [
  { src: '/images/skill-1.jpg', alt: 'Работа ученика' },
  { src: '/images/skill-2.jpg', alt: 'Процесс обучения' },
  { src: '/images/skill-3.jpg', alt: 'Готовый результат' },
]

export function SkillImages() {
  return <SkillGallery images={images} loop />
}
```

Без `loop` после последнего слайда кнопка «вперёд» перестаёт переключать изображение. Стили слайдов, размеры изображений и вид стрелок настраиваются в `SkillGallery.module.css`.
