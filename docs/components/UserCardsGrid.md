## UserCardsGrid

Адаптивная сетка карточек пользователей для каталога SkillSwap. Получает подготовленный массив пользователей с их навыками и отображает для каждого пользователя компонент `UserCard`.

Количество колонок автоматически изменяется в зависимости от доступной ширины контейнера. Расстояние между карточками — `24px`, минимальная желаемая ширина карточки — `324px`.

### Props

```ts
interface CatalogItem {
  user: User
  skills: Skill[]
}

interface UserCardsGridProps {
  items: CatalogItem[]
}
```

- `items` — массив элементов каталога. Каждый элемент содержит пользователя `user` и массив всех его навыков `skills`.
- `user` — объект пользователя типа `User`, содержащий его идентификатор, имя, возраст, город, аватар и другие данные.
- `skills` — массив навыков пользователя типа `Skill[]`, включающий навыки типов `teach` и `learn`. Разделение навыков выполняет компонент `UserCard`.

Типы `User` и `Skill` описаны в `src/shared/types`, а существующий тип `CatalogItem` — в `src/features/catalog/model/catalogData.ts`. Повторно объявлять его в коде компонента не требуется.

### Как подключить

```tsx
import { UserCardsGrid } from '@/widgets/UserCardsGrid'
import type { CatalogItem } from '@/features/catalog/model/catalogData'

const items: CatalogItem[] = [
  {
    user,
    skills: userSkills,
  },
]

<UserCardsGrid items={items} />
```

Компонент не загружает данные самостоятельно и не обращается к JSON-файлам. Массив `items` необходимо подготовить и передать из родительского компонента.

Для объединения пользователей с их навыками можно использовать существующую функцию `buildCatalogItems` из `src/features/catalog/model/catalogData.ts`.

Для каждого элемента массива создаётся одна `UserCard`. В неё передаются пользователь и все его навыки. Если `items` — пустой массив, карточки не отображаются.

Сетка реализована через CSS Grid с `auto-fit` и `minmax`. Количество колонок зависит от ширины родительского контейнера, без фиксированных медиазапросов. При недостатке места сетка перестраивается в меньшее количество колонок без горизонтального переполнения.
