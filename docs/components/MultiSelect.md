## MultiSelect

Контролируемое поле множественного выбора с нативными checkbox в выпадающем списке.

### Props

- `options: readonly string[]` — допустимые варианты; справочник передаёт родитель.
- `value: string[]` — выбранные значения из родителя.
- `onChange: (value: string[]) => void` — новый массив после выбора или снятия отметки.
- `label?: string` — подпись группы и поля; по умолчанию «Выбор вариантов».
- `error?: string` — внешняя ошибка формы. Непустой текст связан с группой, кнопкой и checkbox через `aria-describedby`, включает `aria-invalid` и оформление ошибки.
- `disabled?: boolean` — блокирует раскрытие и выбор; открытая панель закрывается.
- `required?: boolean` — показывает связанное с полем обозначение обязательности. Проверку выполняет родительская форма.
- `maxSelected?: number` — максимальное количество выбранных значений, неотрицательное целое число. Без prop ограничений нет; `0` запрещает добавление. Снятие отметок разрешено при любом лимите.

Компонент хранит только открытость списка. Повторяющиеся варианты объединяются; выбранные значения отображаются однократно, неизвестные значения не отображаются. `onChange` возвращает новый массив только из допустимых уникальных значений, не изменяя входные массивы. Изменения props не вызывают `onChange`.

В закрытом поле выбранные значения перечислены через запятую; при пустом выборе отображается «Выберите варианты». В пустом списке показано «Нет доступных вариантов». Если родитель передал больше значений, чем разрешает лимит, компонент не обрезает их автоматически и позволяет снимать отметки.

Кнопка имеет `type="button"`, `aria-expanded` и `aria-controls`. Enter/Space раскрывают список, повторное нажатие кнопки закрывает его. Tab/Shift+Tab перемещают фокус, Space переключает checkbox. Escape закрывает список и возвращает фокус кнопке. ID создаются через `useId`, подписи связаны с элементами управления.

### Как подключить

```tsx
import { useState } from 'react'
import { MultiSelect } from '@/shared/ui/MultiSelect'

const options = ['Рисование', 'Музыка', 'Танцы'] as const

export function FormExample() {
  const [value, setValue] = useState<string[]>([])
  const [error, setError] = useState('')

  return (
    <form
      onSubmit={(event) => {
        event.preventDefault()
        const hasSelection = value.some((item) => options.some((option) => option === item))
        setError(hasSelection ? '' : 'Выберите хотя бы один навык')
        if (!hasSelection) return
        // Здесь форма отправляет выбранные значения.
      }}
    >
      <MultiSelect
        label="Навыки"
        options={options}
        value={value}
        onChange={(nextValue) => {
          setValue(nextValue)
          setError('')
        }}
        required
        maxSelected={2}
        error={error}
      />
      <button type="submit">Продолжить</button>
    </form>
  )
}
```

`required` не назначается отдельным checkbox: это потребовало бы выбрать каждый из них. Компонент не создаёт скрытых полей для браузерной валидации и не генерирует ошибок самостоятельно. Значение и правила проверки, включая обязательность и бизнес-ограничения, остаются у формы; `disabled` следует учитывать при её проверке. Для отправки форма использует контролируемый массив, автоматическая сериализация через `FormData` не предусмотрена.
