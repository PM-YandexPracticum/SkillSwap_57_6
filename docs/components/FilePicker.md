## FilePicker

Управляемый выбор одного файла с проверкой MIME-типа и необязательного ограничения размера. Значение хранит родитель. Компонент использует настоящий `input type="file"`, доступный с клавиатуры, и показывает имя выбранного файла.

### Props

| Prop | Тип | Обязательный | Назначение |
| --- | --- | --- | --- |
| `value` | `File \| null` | Да | Выбранный файл или `null`, если файла нет. |
| `onChange` | `(file: File \| null) => void` | Да | Передаёт валидный файл после проверки или `null` при удалении. |
| `acceptedTypes` | `readonly string[]` | Да | Допустимые MIME-типы. Используются для `accept` и точной проверки `file.type`. |
| `maxSizeBytes` | `number` | Нет | Максимальный размер в байтах включительно. Если не задан, размер не ограничивается. |
| `disabled` | `boolean` | Нет | Блокирует выбор и удаление файла. |
| `error` | `string` | Нет | Внешняя ошибка формы; отображается, если локальной ошибки нет. |
| `onValidationChange` | `(error: string \| null) => void` | Нет | Сообщает локальную ошибку проверки или `null` при её очистке. |

### Как подключить

```tsx
import { useState } from 'react'
import { FilePicker } from '@/shared/ui/FilePicker'

export function FilePickerExample() {
  const [file, setFile] = useState<File | null>(null)

  return (
    <FilePicker
      value={file}
      onChange={setFile}
      acceptedTypes={['image/jpeg', 'image/png']}
      maxSizeBytes={2 * 1024 * 1024}
    />
  )
}
```

### Поведение

- MIME-тип и размер проверяются до вызова `onChange`. В примере допускаются JPEG и PNG размером до 2 097 152 байт включительно.
- Невалидный файл не заменяет предыдущий: `onChange` не вызывается, локальная ошибка отображается и передаётся через `onValidationChange`.
- Успешный выбор очищает локальную ошибку и сообщает `onValidationChange(null)`. Кнопка «Удалить файл» также очищает локальную ошибку и вызывает `onChange(null)`. После удаления тот же файл можно выбрать снова.
- Отмена диалога сохраняет значение и состояние ошибки.
- Внешняя замена файла или сброс `value` в `null` очищает локальную ошибку и сообщает `onValidationChange(null)`. Подтверждение родителем обычного выбора или удаления не дублирует уведомление; смена ссылки callback сама по себе его не вызывает.
- Внешний `error` остаётся под управлением родителя. Ошибка связана с полем через `aria-describedby`; непустая ошибка включает `aria-invalid`.

Обязательность файла проверяет родительская форма. Предпросмотр и drag-and-drop относятся к отдельному ImagePicker (Issue #42) и здесь не реализованы.
