## UserCard

Карточка пользователя для каталога. Показывает аватар, имя, город, возраст и навыки пользователя в двух блоках: «Может научить» и «Хочет научиться».

### Props

```ts
interface UserCardProps {
  user: User
  skills: Skill[]
}
```

- `user` - пользователь, которого показывает карточка: из него берутся имя, город, возраст и аватар. Если `avatarUrl` равен `null`, показывается заглушка с первой буквой имени.
- `skills` - все навыки этого пользователя, и `teach`, и `learn`. Карточка сама делит их по блокам по полю `type`. В каждом блоке видны первые 2 навыка, остальные сворачиваются в «+N». Если навыков в блоке нет, показывается текст «Пока нет навыков».

Типы `User` и `Skill` описаны в `src/shared/types`.

### Как подключить

```tsx
import { UserCard } from '@/entities/user/ui/UserCard'

<UserCard
  user={user}
  skills={skills.filter((skill) => skill.authorId === user.id)}
/>
```

Карточка не загружает данные сама: `user` и `skills` нужно передать от родителя. Она занимает всю ширину и высоту родительского блока, поэтому её размер задаёт сетка каталога.

Каждый навык в карточке - ссылка на `/skill/:id`. Кнопка «Подробнее» ведёт на первый навык `teach` (если его нет, на первый `learn`).
